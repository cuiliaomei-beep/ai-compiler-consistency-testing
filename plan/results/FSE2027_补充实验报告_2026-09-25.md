## P1-1 最近方法对照

**TorchProbe**（`results/p11_baselines/TORCHPROBE.md`）。论文无仓库链接；作者 soodoshll 的 `temisu` 仓库（提交 `3aa039c4`，2023-03-20，1087 行）即其实现。原样运行因硬编码 `device='cuda'` 失败；两处改动后在 Python 3.14 / torch 2.14 / nnsmith 0.1.0 上可运行：驱动脚本把 device 参数化并限定种子数，`mutator.py` 一行 `random.sample(dict.items())` 改为 `list(...)`（Python ≥ 3.11 必需）。

| 项 | 值 |
|---|---|
| 适用程序 | 29 程序受控语料中 3 个可表达为 TorchProbe 种子（其余：控制流 16、Python 读取张量元数据 11、无渲染器的算子等）；185 程序 Python 语料 0 个 |
| 自有种子上的运行 | `max_nodes=10` 35 个种子 175 个测试、`max_nodes=20` 10 个种子 47 个测试：全部通过，0 不一致，0 崩溃，0 无效（每个变异程序在 eager 下也与 oracle 一致） |
| 墙钟 | 175 测试 583.9 s（中位 2.79 s/测试，首次编译 18.7 s）；47 测试 349.4 s（与 P1-2 并行，偏高） |
| 与已报缺陷对应 | 无；与新发现对应 | 无 |
| 反向对照（Setting B） | TorchProbe 的 35 个种子程序装入本方法 harness（每程序自带一个输入、冷启动 eager vs 编译、全部 oracle）：未变异 5/19，四种变异后 6/19（多出 `capture_swallow_exception`，靠 `insert_tcb` 的恒真分支让 eager 抛出）；在未修改编译器上 0 误报。harness 原始计数 6/19 与 15/19 含两类人为项：注入故障包装器 `_make_scalar_boundary` 对外部程序的张量参数做 `if tensor` 抛错（NNSmith 那腿的 6/19 也含一个，去掉后 NNSmith 为 5/19）；同一进程数百次 compile/reset 后 Dynamo 追踪报 `dictionary changed size during iteration`（Python 3.14 下 `get_items_from_dict` 迭代活 `globals().items()` 与 GC 回调竞争；上游 PR #191281 已于 2026-08-20 合入 main，v2.14.0 仍是旧代码；单独运行不复现，不报 issue） |

## P1-2 真实缺陷的 oracle 分析（独立根因）

统计对象：73 项 − 5 跨编译器 − 10 流水线外 = 58 项，评论并入父 issue、同根因合并后 **52 个独立根因**，127 个子用例（每篇稿件列出的触发程序）。每个子用例 eager 与编译各执行一次（子进程、干净缓存），所有可观察量存入同一条轨迹，三档 oracle 离线从同一轨迹判定（复用 `tcc.oracle` / `tcc.observe`）。

| | T1 值 + 常规崩溃/异常 | T2 + 元数据 | T3 + 别名/状态/梯度/异常路由/多精度/进程 | 本机不可复现 |
|---|---|---|---|---|
| 全部子用例（51 个根因可复现） | 36 | 38 | 51 | 1（B5 需 CUDA） |
| 仅主子用例 | 34 | 38 | 51 | |

最弱报警档：T1 36、T2 2（B15 dtype、B25 stride）、T3 13（B12、C5、C22、C23、C37 异常路由"验证丢失"族；C1 反向异常路由；B18 异常类型；C8 别名；C11、C41 副作用；C34 梯度；C40 多精度参照；C46 进程在调用后销毁时崩溃）。

误报（同一追踪器和三档跑在一致的对照集上）：29 个未改动语料程序 T1/T2/T3 均 0；autocast 阴性结果集 462 算子 × 2 dtype = 924 样本，三档各 2（`bilinear`、`linalg.polar` 在 bf16 下几个 ULP 的值差，论文的 3e-2 容差不会报）。T2、T3 相对 T1 不增加误报。

人工复核时间：台账只有 9 月 22 日有钟点，可给上界：C41/C42 扫描→成稿 ≤ 15 min、成稿→提交 ≤ 19 min；C44 ≤ 20 min；C40 ≤ 1 h 45 min；C46 ≤ 1 h 14 min；C37 50 min + ≤ 45 min。其余"未记录"。

harness 观察：`tcc/oracle.py` 的浮点比较在 eager 输出含 NaN 时容差变为 NaN 而屏蔽所有差异（C13 靠位置级 NaN 检查才在 T1 报警）；`_exact_equal` 把 int/bool dtype 差算作值差；B7 依赖进程内先跑过一次 jvp。`tcc/` 未改，记入台账待修。
