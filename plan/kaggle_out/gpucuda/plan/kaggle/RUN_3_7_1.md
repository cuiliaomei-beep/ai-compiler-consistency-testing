# Kaggle 操作清单：第 3 项（GPU 上的新扫描）、第 7 项（绑定形式变体上 GPU）、第 1 项（§21 同设备版本对）

三件事各用一个 notebook。公共准备只做一次。

## 0. 公共准备（一次）

1. 本机已重打 `toxic_compile/plan_kaggle.zip`（含 `reproducers_models/`、新扫描、`scripts/build_benchmark.py` 的新参数）。
2. Kaggle → 左侧 **Datasets** → 打开你的 `tcc-plan` 数据集 → 右上 **⋮ → New version** → 上传新的 `plan_kaggle.zip`（和 `plan/kaggle/bootstrap.sh`）→ Create。
3. 之后每个 notebook 的 **Add Input** 选 `tcc-plan`，并在输入面板里确认用的是最新版本（下拉能选 version）。
4. 每个 notebook 右侧 Settings：Internet **On**（第 3、7 项 Accelerator 选 **GPU T4 x2**；第 1 项选 **None**，用 CPU）。
5. 每个 notebook 的第一个 cell 都是这段（找 run.py、拷到 working、装依赖、自检）：

```python
import os, shutil, glob
src = os.path.dirname(glob.glob("/kaggle/input/**/run.py", recursive=True)[0])
shutil.copytree(src, "/kaggle/working/plan", dirs_exist_ok=True)
%cd /kaggle/working/plan

```

看到 `10/10 checks passed` 即可。跑长任务前用 **Save Version → Save & Run All (Commit)**，否则 20 分钟无操作会断。

## 第 1 项：§21 同设备版本对（CPU notebook × 2 次运行，各约 1.5 小时）

目的：同一批 `reproducers_gh/` 在**同一台 Linux CPU 机器**上分别用 torch 2.10.0 和 2.14.0 跑，得到严格的 buggy/fixed 对。Accelerator 选 **None**。

### 运行 A：torch 2.10.0

第二个 cell：

```python
%cd /kaggle/working/plan
!pip -q install torch==2.10.0 --index-url https://download.pytorch.org/whl/cpu
!python -c "import torch; print(torch.__version__)"      # 2.10.0+cpu
!python run.py campaign --from-dir reproducers_gh --backend inductor --reruns 2 --max-contexts 12 --test-budget 16 --time-budget 180 --isolate --child-timeout 900 --out reports_gh_cpu_2.10
!python scripts/gh_summary.py reproducers_gh reports_gh_cpu_2.10
```

Save & Run All，结束后下载 `reports_gh_cpu_2.10`。

### 运行 B：torch 2.14.0

新建 notebook（或同一个改版本重跑），第二个 cell 把版本和目录换成 2.14.0：

```python
%cd /kaggle/working/plan
!pip -q install torch==2.14.0 --index-url https://download.pytorch.org/whl/cpu
!python -c "import torch; print(torch.__version__)"      # 2.14.0+cpu
!python run.py campaign --from-dir reproducers_gh --backend inductor --reruns 2 --max-contexts 12 --test-budget 16 --time-budget 180 --isolate --child-timeout 900 --out reports_gh_cpu_2.14
!python scripts/gh_summary.py reproducers_gh reports_gh_cpu_2.14
```

下载 `reports_gh_cpu_2.14`。

### 本机合成基准

两个目录放到本机 `plan/` 下后：

```
python scripts\build_benchmark.py --old reports_gh_cpu_2.10 --old-version "2.10.0+cpu (Kaggle CPU)" --new reports_gh_cpu_2.14 --new-version "2.14.0+cpu (Kaggle CPU)" --verified --fix-status
```

它会重写 `benchmark/historical_bugs.json`：`Kind: fixed` 的条目标为 `Verified: true`（同设备），并用 GitHub API 补修复提交（无 token 时每小时 60 次请求，26 条约需 1.5 小时，可去掉 `--fix-status` 先出结果）。

### 注意

- pip 装 torch 需要 Internet On；2.10 的 CPU 轮子约 200 MB，2.14 约 250 MB。
- 若 pip 提示与预装的 torchvision 冲突，加 `--no-deps` 并忽略，campaign 不用 torchvision。
- 两次运行如果不在同一天也没关系，机器型号一致（Kaggle CPU 实例）即可；`SUMMARY.md` 顶部会记录 `torch` 版本和 device，合成时会写进 provenance。
